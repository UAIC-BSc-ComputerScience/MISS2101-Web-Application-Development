# MISS2101: Web Application Development (#WADe)

Repository dedicat cursului **Web Application Development** (#WADe / MISS2101), din cadrul programului de **Master în Inginerie Software (MISS)**, Anul II, Semestrul I, la **Facultatea de Informatică, Universitatea „Alexandru Ioan Cuza” din Iași (UAIC)**.

- **Titular curs:** Prof. Dr. habil. Sabin-Corneliu Buraga
- **Site oficial curs:** [https://profs.info.uaic.ro/sabin.buraga/teach/courses/wade/](https://profs.info.uaic.ro/sabin.buraga/teach/courses/wade/)
- **Programa detaliată (WADe Film):** [https://profs.info.uaic.ro/sabin.buraga/teach/courses/wade/web-film.html](https://profs.info.uaic.ro/sabin.buraga/teach/courses/wade/web-film.html)

## Structura Repozitoriului

Acest folder a fost populat complet cu toate resursele oficiale descărcate și organizate conform structurii de mai jos:

```
MISS2101-Web-Application-Development/
├── course/
│   ├── ro/                  # Toate cele 15 prezentări oficiale de curs (PDF în limba română)
│   │   ├── web00Introducere.pdf ... web12SemanticWeb-CunostinteWeb_UtilizariPragmatice.pdf
│   │   └── README.md        # Indexul detaliat al fiecărei prezentări și concepte asociate
│   └── eng/                 # Rezervat pentru notițe, rezumate sau traduceri în limba engleză
├── lab/
│   ├── demos/               # Pachetele oficiale de laborator (ZIP + directoare extrase)
│   │   ├── rdf/ (rdf.zip)       # Exemple de aserțiuni și grafuri RDF (Turtle, XML, N3)
│   │   ├── shacl/ (shacl.zip)   # Constrângeri și validare SHACL
│   │   ├── sparql/ (sparql.zip) # Interogări SPARQL pe DBpedia, DBLP, Nobel, Revyu etc.
│   │   ├── rdfs/ (rdfs.zip)     # Taxonomii și tezaure definite cu RDFS și SKOS
│   │   ├── owl/ (owl.zip)       # Ontologii Web modelate în OWL
│   │   └── owl-dl/ (owl-dl.zip) # Raționamente logice și deducție în OWL DL
│   ├── tutorials/           # Ghiduri practice de laborator (Schema.org Microdata & RDFa)
│   └── README.md            # Ghid complet de laborator, unelte recomandate și linkuri
├── bibliography/            # Toate cele 15 articole și lucrări academice menționate în silabus
│   ├── Knowledge_Graphs_Survey_Hogan_ACM_CSUR_2021_arXiv_2003_02320.pdf
│   ├── Ontology_Development_101_Stanford.pdf
│   ├── Description_Logic_Primer_Kroetzsch_arXiv_1201_4089.pdf
│   ├── DBpedia_Technology_Tutorial_CEUR_Vol3064.pdf
│   ├── ... (15 lucrări descărcate în format PDF)
│   └── README.md            # Catalogul bibliografic detaliat cu autori și legături la curs
├── project/
│   ├── web-projects.html    # Pagina oficială a cerințelor de proiect, arhitectură și bonusuri
│   ├── projects_index.html  # Propunerile detaliate de teme de proiect (DiO, kro, WAS)
│   └── README.md            # Rezumatul cerințelor, etapelor de livrare și temelor
├── exam/
│   ├── web-exam.html        # Pagina oficială privind evaluarea și examinarea
│   └── README.md            # Formula de notare, componente obligatorii/opționale, condiții
├── docs/
│   ├── web-film.html        # Copia locală a silabusului WADe
│   ├── syllabus.md          # Sinteza programării pe 14 săptămâni + suplimente
│   ├── web.css              # Foaia de stil oficială
│   ├── web-biblio.html      # Bibliografie generală WADe
│   └── web-contact.html     # Date de contact și reguli
├── app/                     # Spațiu pentru codul sursă al proiectului semestrial
├── research/                # Notițe de cercetare și investigații suplimentare
└── sem/                     # Materiale de seminar (dacă este cazul)
```
