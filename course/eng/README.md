# Web Application Development (#WADe) - English Materials

The official slide presentations for the course are provided in Romanian in [`../ro/`](../ro/README.md).

This folder is reserved for English study notes, summaries, or translated slides.

## Key Syllabus Topics Covered
1. **Week 1:** Web Application Development: Concepts & Vision
2. **Week 2:** Service-Based Architecture & REST API Design
3. **Week 3-5:** Modern Web Architectures (Microservices, Microfrontends, OpenAPI, Serverless, GraphQL, Web Auth)
4. **Week 5:** Data and Knowledge Modeling Aspects
5. **Week 6:** Resource Description Framework (RDF) & HTML Microdata
6. **Week 7:** RDF Data Management & SPARQL Queries + RDFa
7. **Week 8:** Project Preparation & Modeling Exercises
8. **Week 9:** RDF-Based Application Architectures & Linked Data (LOD)
9. **Week 10:** Vocabularies, Taxonomies & Thesauri with RDF Schema and SKOS
10. **Week 11:** Specifying Ontologies in OWL
11. **Week 12:** OWL 2, Description Logics (DL) & Automated Reasoning
12. **Supplements:** Ontology Engineering & Pragmatic Uses of Knowledge Graphs
