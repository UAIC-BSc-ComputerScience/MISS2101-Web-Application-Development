## Planificare Săptămânală

### Săptămâna 1
- **Prezentare Introductivă:** [web00Introducere.pdf](../course/ro/web00Introducere.pdf) – Introducere & Informații administrative
- **Curs 1:** [web01Concepte.pdf](../course/ro/web01Concepte.pdf) – Dezvoltarea Aplicațiilor Web: Concepte & Viziune
- **Termeni cheie:** Web, arhitectură, social Web, semantic Web, date, modelare, standarde, viziune
- **Laborator:** Recapitulare Tehnologii Web

### Săptămâna 2
- **Curs 2:** [web02ServiciiWeb-REST-API.pdf](../course/ro/web02ServiciiWeb-REST-API.pdf) – Dezvoltarea aplicațiilor Web bazate pe servicii. REST
- **Termeni cheie:** Web, serviciu, SOA, REST, HTTP, reprezentare, resursă, API, exemple
- **Laborator:** Discuții teme prezentări tehnice studențești + proiectare și consum de API-uri REST

### Săptămâna 3
- **Curs 3:** [web03DezvoltareaAplicatiilorWeb-Servicii-API-Mashup-Arhitectura.pdf](../course/ro/web03DezvoltareaAplicatiilorWeb-Servicii-API-Mashup-Arhitectura.pdf) – Aspecte arhitecturale în dezvoltarea aplicațiilor Web
- **Termeni cheie:** Inginerie Web, arhitectură, microservicii, microfrontends, OpenAPI, serverless, 12-factor app
- **Laborator:** Arhitecturi Web, servicii & serverless + discuții pe [propunerile de proiecte WADe](../project/README.md)

### Săptămâna 4
- **Curs 4:** [web03DezvoltareaAplicatiilorWeb-Servicii-API-Mashup-Arhitectura.pdf](../course/ro/web03DezvoltareaAplicatiilorWeb-Servicii-API-Mashup-Arhitectura.pdf) (continuare)
- **Termeni cheie:** Securitate API, OAuth 2.0, JWT, GraphQL, Single Page Applications (SPA), Progressive Web Apps (PWA)
- **Laborator:** Proiectare API via OpenAPI 3.1

### Săptămâna 5
- **Curs 4 (bis):** [web03DezvoltareaAplicatiilorWeb-Servicii-API-Mashup-Arhitectura.pdf](../course/ro/web03DezvoltareaAplicatiilorWeb-Servicii-API-Mashup-Arhitectura.pdf) (finalizare) – CORS, JAMstack, integrare aplicații
- **Curs 5:** [web04ModelareaCunostintelor.pdf](../course/ro/web04ModelareaCunostintelor.pdf) – Aspecte privind modelarea datelor și a cunoștințelor
- **Termeni cheie:** Model, conceptualizare, etichetare (tagging), folksonomii, Web science
- **Laborator:** Prezentări tehnice studențești

### Săptămâna 6
- **Curs 6:** [web05ModelulRDF.pdf](../course/ro/web05ModelulRDF.pdf) – Modelarea datelor în RDF (Resource Description Framework)
- **Termeni cheie:** Model RDF, triple, adnotare semantică, vocabulare, JSON-LD, Turtle
- **Demo:** [demos/rdf/](../lab/demos/rdf/) ([rdf.zip](../lab/demos/rdf.zip))
- **Laborator (Supliment):** Modelarea datelor în HTML – Tutorial: [web-Microformats-HTML5schema.org.pdf](../lab/tutorials/web-Microformats-HTML5schema.org.pdf) (Schema.org HTML5 Microdata)

### Săptămâna 7
- **Curs 7:** [web06ManagementulDatelorRDF-SPARQL.pdf](../course/ro/web06ManagementulDatelorRDF-SPARQL.pdf) – Managementul datelor RDF. Accesarea datelor RDF via SPARQL
- **Termeni cheie:** RDF, triple stores, validare SHACL, SPARQL, endpoint-uri
- **Demo:** [demos/shacl/](../lab/demos/shacl/) ([shacl.zip](../lab/demos/shacl.zip)), [demos/sparql/](../lab/demos/sparql/) ([sparql.zip](../lab/demos/sparql.zip))
- **Laborator (Supliment):** Modelarea datelor în HTML – Tutorial: [web-RDFa-TripleRDFinHTML.pdf](../lab/tutorials/web-RDFa-TripleRDFinHTML.pdf) (RDFa)

### Săptămâna 8
- **Pregătire proiect:** Fără cursuri regulate – definitivarea arhitecturii și a primului livrabil pentru proiect.
- **Experimente:** Modelare RDF și interogări SPARQL (YASGUI, date de transport public, prefix.cc).

### Săptămâna 9
- **Curs 8:** [web07ArhitecturaAplicatiilorRDF-LinkedData.pdf](../course/ro/web07ArhitecturaAplicatiilorRDF-LinkedData.pdf) – Arhitectura aplicațiilor bazate pe RDF. Linked Data
- **Termeni cheie:** Linked Open Data (LOD), Linked Data Platform (LDP), principii 5-Star Data, publicare date legate
- **Laborator:** Experimente RDF și SPARQL pe date bibliografice DBLP

### Săptămâna 10
- **Curs 9:** [web08Taxonomie-RDFSchema-Lexicon-SKOS.pdf](../course/ro/web08Taxonomie-RDFSchema-Lexicon-SKOS.pdf) – Modelarea vocabularilor, taxonomiilor și tezaurelor cu RDF Schema și SKOS
- **Termeni cheie:** Vocabulare controlate, taxonomii, tezaure, RDFS, SKOS, inferență
- **Demo:** [demos/rdfs/](../lab/demos/rdfs/) ([rdfs.zip](../lab/demos/rdfs.zip))
- **Laborator:** Crearea taxonomiilor și a tezaurelor semantice (ACM CCS, GEMET etc.)

### Săptămâna 11
- **Curs 10:** [web09SemanticWeb-Ontologii-OWL.pdf](../course/ro/web09SemanticWeb-Ontologii-OWL.pdf) – Specificarea ontologiilor în OWL (Web Ontology Language)
- **Termeni cheie:** Cunoștințe, ontologii, OWL, clase, proprietăți, indivizi, restricții axiomatice
- **Demo:** [demos/owl/](../lab/demos/owl/) ([owl.zip](../lab/demos/owl.zip))
- **Laborator:** Modelarea cunoștințelor în Protégé / OWL

### Săptămâna 12
- **Curs 11:** [web10SemanticWeb-Ontologii-OWL2-BazeDeCunostinte-LogicileDescrierii-Rationamente.pdf](../course/ro/web10SemanticWeb-Ontologii-OWL2-BazeDeCunostinte-LogicileDescrierii-Rationamente.pdf) – Specificarea ontologiilor via OWL 2. Logici ale descrierii. Raționamente
- **Termeni cheie:** OWL 2, logici ale descrierii (DL), raționament automat, inferență, consistență
- **Demo:** [demos/owl-dl/](../lab/demos/owl-dl/) ([owl-dl.zip](../lab/demos/owl-dl.zip))
- **Laborator:** Modelarea cunoștințelor și inferență în OWL 2

### Săptămâna 13
- **Zile libere / Consultații:** Q&A privind proiectele WADe

### Săptămâna 14
- **Evaluare finală proiecte:** Prezentarea soluțiilor software dezvoltate
