Web Application Development

syllabus (aka the WADe film)

Resources provided by this document only complement and do not substitute the students' pro-active involvement during the classes – consult the WADe timetable [RO].

  • Week #1 (28 September—2 October 2026)

Week #1

  • Presentation: Introduction & Administrative Info

  • Lecture: Web Application Development: Concepts & Vision

    Web, architecture, social Web, semantic Web, data, modeling, standards, vision

  • Resources: Tim Berners-Lee: The Next Web, The Rationale for Semantic Technologies, Making Your Data Ready for Agentic AI, Ontologies Are So Back: Why AI Agents Are Reviving the Semantic Web

  • Lab: Recapitulating Web Technologies

Week #2

  • Lecture: Service-based Web Application Development. REST

    Web, service, SOA, REST, HTTP, representation, resource, API, examples

  • Demo: PokéAPI, Star Wars API, Star Trek API, APIfootball, Open Banking Tracker

  • Resources: SOA: Principles of Service Orientation, SOA (InfoQ); REST: Learn REST: A RESTful Tutorial, REST for an Hour, Designing a True REST State Machine, REST State Machine Revisited, API Technical and Data Standards (gov.uk), REST API Guidelines (Microsoft)

  • Tools: Awesome REST, Public APIs

  • Lab: Discussions on student presentation topics + designing and using REST APIs – think about Serialization Formats

Week #3

  • Lecture: Web Application Development: Architectural Aspects

    Web, engineering, architecture, microservice, microfrontend, OpenAPI, serverless

  • Demo: Web engineering: Software Engineering at Google, GitLab Architecture, Slack Architecture, Stack Overflow: The Architecture; technology stacks: Todo-Backend, Tech Stacks, Real Life Architectures; microservices: Sock Shop: A Microservices Demo Application, Microservices @ Netflix; microfrontends: Feed Me; serverless: OpenFaaS Architecture, Exploring Serverless Use-Cases

  • Resources: Web engineering: Software Architecture Guide, The Frugal Architect, Architecture Playbook, aim42, The 12-Factor App, Contemporary Front-end Architectures; REST API design: API Stylebook, Web APIs: From Start to Finish, OpenAPI Initiative; microservices: How to break a Monolith into Microservices, Microservice Architecture, Microservices @ DZone; microfrontends: Microfrontend Architecture, Microfrontends; serverless: Serverless Architectures

  • Tools: Free Public APIs, APIs Guru, OpenAPI Tools, Awesome Microservices, Awesome Serverless; AWS case-study: The Open Guide to Amazon Web Services

  • Lab: Web application architectures, (micro)services & serverless + discussion on WADe project proposals

Week #4

  • Lecture: Web Application Development: Architectural Aspects (continued)

    Web, architecture, API security, OAuth, JWT, GraphQL, SPA, PWA

  • Demo: GraphQL: Rapid Development with GraphQL Microservices (Netflix), GitHub GraphQL API, Shopify Storefront GraphQL API, Using GraphQL for High-Performing Mobile Applications (Shopify), PizzaQL

  • Resources: Web auth: The Copenhagen Book; OAuth: An OAuth 2.0 Introduction for Beginners, OAuth 2 Simplified; GraphQL: GraphQL, The Fullstack Tutorial for GraphQL; others: Single Page Application, Progressive Web Apps (MDN)

  • Tools: JSON Web Tokens; GraphQL: Awesome GraphQL, Public GraphQL APIs

  • Lab: Web application architectures, (micro)services & serverless – API design via OpenAPI

Week #5

  • Lecture: Web Application Development: Architectural Aspects (continued)

    Web, architecture, CORS, JAMstack, use cases

  • Demo: Web Architecture of the Chaos Computer Club (media.ccc.de) multimedia system

  • Resources: Cross-Origin Resource Sharing (MDN), CORS Tutorial (Auth0), JAMstack, The Web's Next Transition, Application Integration, Code Catalog

  • Tools: Awesome JAMstack

  • Lecture: Aspects regarding Data and Knowledge Modeling

    model, conceptualization, tagging, folksonomy, use cases, Web, science

  • Demo: What is Computation?, Knowledge Types, Cognitive Bias

  • Resources: A guide to NLP, Tagging, Museum of Obsolete Media, Dev Encyclopedia

  • Tools: jq (An Introduction to jq), Miller, Pandoc

  • Lab: Topics on Web application development

Week #6

  • Lecture: Data Modeling in RDF (Resource Description Framework)

    Web, model, RDF, data, annotation, vocabulary, JSON-LD, examples

  • Demo: RDF assertions (.zip archive, 77K), DCMI, JSON-LD in the wild

  • Resources: The Future of the Web: From Strings to Things, Semantic Social Web, RDF Primer (W3C), JSON-LD, FAIR Principles

  • Tools: Visual Studio Code extensions for RDF et al., RDF Sketch Editor, JSON-LD Playground, JSON-LD Libraries

  • Lab: Data Modeling in HTML

    • Tutorial: Data Modeling in HTML: Schema.org HTML5 Microdata

      Web, model, HTML, annotation, microdata, schema.org, examples

    • Demo: Schema.org Markup for Emails, Personas and UsabilityTest Schema Extensions, Add review to Goodreads from Schema.org markup, Google Structured Data

    • Resources: Bots (Imperva), Getting Started with Schema.org using Microdata, The future of the Web, isn't the Web, Semantic HTML (GitHub)

    • Tools: Schema.org Markup Validator, Structured Data Sniffer (OpenLink), Rich Results Test (Google), Awesome Web Crawler, Scrapinghub

Week #7

  • Lecture: RDF Data Management. Accessing RDF Data via SPARQL

    Web, RDF, data, management, triple store, SHACL, SPARQL, examples

  • Demo: SHACL examples (.zip archive, 5K), SPARQL queries (.zip archive, 73K) – case-studies: SPARQL posts on Bob DuCharme's blog, Triply Academy, RDF & SPARQL (Wolfram)

  • Resources: Validating RDF, A Survey of RDF Stores & SPARQL Engines for Querying Knowledge Graphs, DB-Engines Ranking of RDF Stores

  • Tools: RDF storage: Amazon Neptune, Fluree, OntoText GraphDB (real-life usage), MarkLogic (tutorial), OpenLink Virtuoso (SPARQL use-cases), Stardog; RDF processing: Apache Jena, ARC2, dotNetRDF, Eclipse RDF4J, RDF JavaScript Libraries, Redland; RDF conversion: EasyRdf, Tarql; RDF visualization: rdfpuml; SPARQL endpoints: DBpedia, Wikidata Query (tutorial + various examples), DBtune, Bibliothèque Nationale de France, Nomisma (examples), EU Open Data Portal; SHACL: SHACL Playground, SHACL Play!, SHACL API

  • Lab: Data Modeling in HTML

    • Tutorial: Data Modeling in HTML: RDFa

      Web, model, HTML, data, annotation, RDF, RDFa, vocabulary, tools, examples

    • Demo: Examples of Structured Data Embedded within HTML

    • Resources: RDFa—Linked Data in HTML, 2025 Web Almanac: SEO – Structured Data (HTTP Archive), 2024 Web Almanac: Structured Data (HTTP Archive), Web Data Commons

    • Tools: RDFa Libraries

Week #8

  • No regular classes – project preparation

  • RDF and SPARQL experiments with YASGUI – exercises: create a RDF model for open data regarding the local public transportation [RO], Google alternatives, popular tech stacks, Web application vulnerabilities, food facts (provide also the equivalent schema.org or RDFa constructs to be included into HTML documents as JSON-LD); consider also prefix.cc

Week #9

  • Lecture: Architecture of RDF-based Applications. Linked Data

    Web, RDF, data, application, architecture, development, LOD, LDP, principles, examples

  • Demo: Using Wikidata to Generate Better Artwork, dokieli, Scholia, SPARQL Anything, Semantic MediaWiki, Full-stack Linked Data: Lessons from Building an RDF Web Application

  • Case-studies: DBpedia (The DBpedia Technology Tutorial), Wikidata (Introduction to Wikidata for Librarians), SemOpenAlex, IMGpedia, A Comparative Study of State-of-The-Art Linked Data Visualization Tools

  • Resources: Towards 5-Star Data, Why 5-Star Data?, Linked Data: Evolving the Web into a Global Data Space, Linked Data Patterns, Linked Data Fragments, Collaborative Data Patterns

  • Tools: Simple Linked Data Deployment Tutorial – using RDF Turtle, Simple Linked Data Deployment Tutorial – using JSON-LD, grlc, Wikibase, CKAN, Solid Project, Linked Data Fragments Software, Open Semantic Search

  • Lab: RDF and SPARQL experiments regarding dblp data – consult also A guided tour of the dblp KG

Week #10

  • Lecture: Modeling Vocabularies, Taxonomies, and Thesauri with RDF Schema and SKOS

    Web, RDF, model, controlled vocabulary, taxonomy, thesaurus, RDF Schema, SKOS, inference

  • Demo: RDF Schema + SKOS (.zip archive, 24.5K), SPARQL full-text Wikipedia searching and Wikidata subclass inferencing, Transform data into knowledge with PoolParty Semantic Suite and Amazon Neptune (Amazon)

  • Case-studies: Getty Vocabularies, Public Vocabularies, Social Semantic Web Thesaurus, NASA Conceptual Models, UNESCO Thesaurus, dblp RDF schema

  • Resources: What is RDF Schema?, What else can I do with RDF Schema?, Taxonomy management with SKOS, A (Partial) Taxonomy of Machine Learning Features

  • Tools: iQvoc, SKOSMOS, SKOS Play! (practical uses: Visualize PoolParty project data), TemaTres, VocBench (read Editing schemas, ontologies, and SKOS taxonomies with VocBench)

  • Lab: Knowledge modeling with RDF Schema and SKOS – exercises: create RDF-based taxonomies + thesauri by using ACM Computing Classification System, European Multilingual Thesaurus on Health Promotion, GEMET, Intellectual Property Subject Thesaurus, Music Styles

Week #11

  • Resources: Knowledge Graphs, Ontology Development 101: A Guide to Creating Your First Ontology, Ontologies & Cultural Heritage
