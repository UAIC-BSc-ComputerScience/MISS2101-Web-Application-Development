Web Application Development

course description & evaluation

Overview · Evaluation

Overview

The main objectives of the Web Application Development discipline focus on providing a general view regarding knowledge modeling in the context of the evolution towards the Web of data (aka linked data) and semantic Web.

The post-graduate students (first semester, Master studies at the Faculty of Computer Science, UAIC) will achieve both theoretical and practical understanding about the development of complex Web applications, including the (micro-)services, on the basis of the existing Web technologies by using various representations, models, methods, practices, and tools regarding knowledge (meta-data, taxonomies, thesauri, ontologies) – for details, consult the main WADe topics.

Evaluation

The assessment procedure consists of the following components:

  • T – a mandatory open book written test focused on specific topics covered by all WADe lectures – omitting supplements, but including lab tutorials on Schema.org HTML5 Microdata (week #6) and RDFa (week #7) – to be organized during the finals session.

    ⚠ Important aspects:

    • Written test duration: maximum 50 minutes.

    • The use of any electronic devices is strictly prohibited!

  • P – an optional technical presentation focused on a specific proposed topic and delivered during the lab classes (weeks #2—#12, usually) by a team of maximum 2 persons.

  • S – an optional software project – to be developed by the same team of 2 students and delivered during the lab classes at the end of the semester (week #14, usually).

Grading formula is G = max (5, T * 0.5 + P * 0.2 + S * 0.3), with T, P, S ∈ [0, 10], if and only if T ≥ 5. The delivery of the project solution S must ensure S ≥ 5.

For optional components, the default value is 0.

Other aspects of interest
