# Laborator: Dezvoltarea Aplicațiilor Web (#WADe)

Acest director conține demonstrațiile practice, exemplele de cod, tutorialele și temele de laborator pentru disciplina **Web Application Development**.

---

## 1. Pachete Practice & Demo-uri (`demos/`)

Pachetele originale `.zip` și fișierele de cod extrase gata pentru explorare:

| Demo | Director Extras | Arhivă ZIP | Descriere & Conținut |
|:---|:---|:---|:---|
| **RDF Assertions** | [`demos/rdf/`](demos/rdf/) | [`demos/rdf.zip`](demos/rdf.zip) | Exemple de modelare și aserțiuni RDF în sintaxele Turtle, XML/RDF și N3. |
| **SHACL Validation** | [`demos/shacl/`](demos/shacl/) | [`demos/shacl.zip`](demos/shacl.zip) | Validarea restricțiilor pe grafuri RDF folosind Shapes Constraint Language (SHACL). |
| **SPARQL Queries** | [`demos/sparql/`](demos/sparql/) | [`demos/sparql.zip`](demos/sparql.zip) | Interogări SPARQL complexe pe endpoint-uri reale (DBpedia, DBLP, BNF, Nobel Prize, Factbook, Revyu etc.). |
| **RDFS & SKOS** | [`demos/rdfs/`](demos/rdfs/) | [`demos/rdfs.zip`](demos/rdfs.zip) | Vocabulare controlate, ierarhii de concepte și tezaure definite cu RDFS și SKOS. |
| **OWL Ontologies** | [`demos/owl/`](demos/owl/) | [`demos/owl.zip`](demos/owl.zip) | Modelarea cunoștințelor prin ontologii Web (clase, proprietăți, instanțe în OWL). |
| **OWL DL Reasoning** | [`demos/owl-dl/`](demos/owl-dl/) | [`demos/owl-dl.zip`](demos/owl-dl.zip) | Exemple practice de inferență și deducție logică folosind OWL DL. |
